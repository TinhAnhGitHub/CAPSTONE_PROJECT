# ASR Task

## Purpose

`asr_chunk_task` transcribes audio chunks extracted from detected video shots. It converts each shot-level WAV file into an `ASRArtifact` with transcript text, timestamps, frame bounds, and duration.

## How It Works

The task implementation is `ASRTask` in `main.py`.

1. `preprocess()` receives a batch of `ASRItem` tuples and returns it unchanged.
2. `execute()` collects temporary audio file paths from the batch.
3. `execute()` sends the whole batch to `QwenASRClient.ainfer()`.
4. `execute()` deletes every temporary audio file in a `finally` block.
5. `execute()` parses model text with `parse_asr_response()`.
6. `execute()` converts frame boundaries to timestamps with `frames_to_timestamp()`.
7. `postprocess()` persists each `ASRArtifact`.
8. `summary_artifact()` writes a transcript table to Prefect artifacts.

## Input

Type: `list[ASRItem]`

`ASRItem` is `tuple[AutoshotArtifact, start_frame, end_frame, audio_path]`.

| Tuple item | Meaning |
|------------|---------|
| `AutoshotArtifact` | Carries video ID, user ID, video URL, FPS, and extension. |
| `start_frame` | First frame of the audio segment. |
| `end_frame` | Last frame of the audio segment. |
| `audio_path` | Local temporary WAV file generated by `preprocess_video_task`. |

## Output

Type: `list[ASRArtifact]`

| Field | Meaning |
|-------|---------|
| `related_autoshot_artifact_id` | Shot detection artifact that produced this segment. |
| `related_video_id` | Source video ID. |
| `metadata.timestamp` | `[start_timestamp, end_timestamp]`. |
| `metadata.frame_num` | `[start_frame, end_frame]`. |
| `metadata.text` | Parsed ASR transcript. |
| `metadata.duration` | Segment duration in seconds. |

## Dask Parallelization

The flow creates ASR batches in `preprocess_video_task`, then calls `asr_chunk_task.map(asr_batches, wait_for=[preprocess_fut])`. Prefect schedules each batch as an independent Dask task. Within each batch, ASR inference is one batched request to the ASR service.

## Algorithm Details

The algorithm is batch transcription plus artifact normalization:

1. Audio boundaries are defined by AutoShot frame segments.
2. `preprocess_video_task` extracts the actual audio files before this task runs.
3. The ASR model sees only local audio paths.
4. The task maps each model response back to the original `(autoshot, start_frame, end_frame)` tuple by `zip(raw_results, preprocessed)`.
5. Timestamps are derived from frame numbers and FPS, so transcript alignment stays consistent with visual segments.

## Downstream Consumers

`audio_segment_task` consumes all `ASRArtifact` objects and optionally merges them into semantically meaningful audio segments.
